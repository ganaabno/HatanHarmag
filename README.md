# Hatan Harmag

Immersive brand website for Hatan Harmag, built from the supplied company reports and official logo.

## Stack

- pnpm workspace + Turborepo
- TanStack Start and file-based TanStack Router
- React 19 + strict TypeScript
- Tailwind CSS v4
- Motion for scroll and interface choreography
- i18next with Mongolian and English content
- Self-hosted Manrope and Prata font subsets

## Run

```bash
pnpm install
pnpm dev
```

Quality checks:

```bash
pnpm typecheck
pnpm lint
pnpm build
```

## Content provenance

Copy, figures, contact details, the official logo, the Sэргээнээ product pack, and documentary photography are derived from the two source PDFs and three logo files in `assets/`. The wide Gobi campaign image was generated specifically for this project using the report's harmag berry and habitat photography as references.
